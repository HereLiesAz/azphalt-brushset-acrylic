# azphalt-brush-acrylic

Brush packages for the "acrylic" collection, each in its own `brushes/<slug>/` folder (manifest.json + LICENSE + assets/tip.png):

- `brushes/acrylic-flat/` — **Flat** — A crisp, hard-edged flat acrylic brush. Rotate with the angle param.
- `brushes/acrylic-round/` — **Round** — A classic soft round acrylic brush with pressure-driven flow.
- `brushes/acrylic-angular-shader/` — **Angular Shader** — A wide, softer flat brush for shading and blocking in color. Rotate with angle.
- `brushes/acrylic-sponge-dab/` — **Sponge Dab** — A porous sponge-textured dab for stippled, uneven coverage.

`node build.js` packs every subfolder into its own `.azp`.
